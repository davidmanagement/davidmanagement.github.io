Embed The Humility Code (JSON / Python)

Substance over theater — living obligation, installable for agents and apps

Public machine-readable pack so builders can load the Code into agents without copy-paste drift. Cite the canonical page when you ship or teach it.

This pack does not replace living the Code. It makes restraint installable: same fourteen articles, same canonical URL, fewer excuses for “we couldn’t embed it.” Prefer obligation over branding. Canonical: https://davidmanagement.github.io/humility-code/.

Files

  • humility_code.json — structured articles + metadata for RAG / policy packs
  • humility_code.schema.json — JSON Schema for validation
  • humility_code.py — Python loader (system_prompt, OpenAI messages, Ollama Modelfile, heuristic lint)
humility_code.json Schema Python loader

Quick start

# Print short system prompt (fetches live SHORT if online; else JSON digest)
python3 humility_code.py --style short

# JSON digest (offline-friendly from humility_code.json)
python3 humility_code.py --style json_digest

# Ollama Modelfile SYSTEM block
python3 humility_code.py --modelfile

# Article checklist
python3 humility_code.py --checklist

Python API:

from humility_code import HumilityCode
hc = HumilityCode.load()  # or HumilityCode.load(fetch=True)
msgs = hc.as_openai_messages("Help me ship safely.")
